The Standard

Built on IEC 61131-3

§
The international standard
IEC 61131-3 (since 1993) defines a common set of programming languages and structures so control software is portable across any vendor's hardware.
⇄
Portability by design
Code written to the standard can be moved between compliant controllers without rewriting — vendor-neutral, future-proof.
★
CODESYS = market leader
The most widely adopted vendor-independent implementation of IEC 61131-3 in the world.

Programming Languages

One IDE, Five Languages

LD
Ladder Diagram
Looks like electrical relay schematics. Most common on factory floors.
Most common
FBD
Function Block Diagram
Drag-and-connect blocks. Great for signal flow and process logic.
ST
Structured Text
Text-based, similar to Pascal/C. High-level procedural language.
Our devs' home turf
SFC
Sequential Function Chart
Step-by-step process logic. Visual state machine for sequential operations.
IL
Instruction List
Assembler-like low-level language. Deprecated by PLCopen — optional use only.

Engineering Capabilities

Why Engineers Like It

Classic PLC Features
  • Ladder, FBD, SFC visual editors
  • Integrated simulator — no hardware needed to test
  • Online change — modify code while the machine runs
  • Variable monitoring & online debugging
  • All major fieldbuses: EtherCAT, Profinet, Modbus, CAN
Modern Software Engineering
  • OOP — inheritance, interfaces, libraries (like real software)
  • Version control integration (Git compatible)
  • Static code analysis & CI/CD-capable workflows
  • Integrated HMI visualization (web, native, mobile)
  • Security: certificates, encryption, threat-modeling editor

Key insight: CODESYS bridges the gap between traditional PLC programming and modern software engineering practices — making it accessible to both OT and IT teams.
